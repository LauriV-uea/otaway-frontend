# Imágenes turísticas

Agrega aquí fotografías locales optimizadas en formato WebP y asígnalas en `src/features/tourism/catalog.ts` con rutas como `/images/plaza-de-los-ponchos.webp`.

Las rutas solo se renderizan desde `/images/`. Si un archivo aún no está disponible o no carga, OtaWay muestra su placeholder visual local.
